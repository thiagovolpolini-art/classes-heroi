# 🦸 Desafio - Criando Classes de um Jogo

Projeto desenvolvido como parte de um desafio da **DIO**, com o objetivo de praticar conceitos básicos de programação utilizando **JavaScript**.

## 📚 Conceitos utilizados

* Variáveis
* Estruturas condicionais
* Funções
* Classes
* Objetos
* Métodos

## 🎮 Sobre o projeto

O programa cria um herói com as seguintes características:

* Nome
* Idade
* Tipo

Dependendo do tipo do herói, ele utiliza um ataque diferente:

* **Mago** → magia
* **Guerreiro** → espada
* **Monge** → artes marciais
* **Ninja** → shuriken

## 💻 Exemplo de saída

```text
Alberto
56
mago
O mago atacou usando magia
```

## 🚀 Tecnologias

* JavaScript
* Node.js

## ▶️ Como executar

No terminal, execute:

```bash
node heroi.js
```
